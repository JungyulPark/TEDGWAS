## 검증 범위

표시된 수치 463개를 원본 full-precision 값과 직접 대조했고 관련 검사 580개가 통과했습니다. 이 검사는 기존 원고의 특정 문자열만 찾는 방식과 달리 실제 CSV·표·Word의 연결을 확인합니다. 독립 재현 코드를 포함했습니다. GitHub 사본에서는 저장소 자료 관리 규칙에 따라 원자료 추출본 5개를 제외했으며, 해당 자료와 원래의 전체 패키지는 로컬에 보관했습니다. 본문 27쪽, 보충자료 13쪽, 커버레터 1쪽의 전체 렌더링을 직접 확인했고, 그림 5개도 검토했습니다.

이 결과는 원고 수치와 파일의 정합성을 뒷받침합니다. 임상적 인과성, 모든 분석의 독립적 재수행, 저자 선언의 사실 여부, 심사 통과를 보증하는 결과는 아닙니다. 특히 전체 MR pipeline을 처음부터 재실행한 것으로 해석하면 안 됩니다.

## eQTLGen 빈도 민감도 분석

**아직 수행하지 않았으며, 원고의 미실행 limitation을 유지했습니다.** 공식 다운로드의 HTTPS 인증서 확인이 실패했고 로컬 R 사용자 패키지 폴더도 읽을 수 없었습니다. 이번 패키지는 앞선 보고서의 ‘분석 미실행 사실을 명시하고 제출’ 경로에 해당합니다. 빈도를 바꿔도 결론이 유지된다는 문장은 추가하지 않았습니다.

추가 분석을 원하는 경우 `reproducibility/Prepare_MAF_inputs.ps1`로 공식 빈도 파일과 R 패키지 상태를 준비할 수 있습니다. 이 명령 자체는 분석을 수행하지 않습니다. 실행법과 완료 판정 기준은 같은 폴더 README에 있습니다. 기존 저장소의 미검증 민감도 스크립트를 실행했다는 이유만으로 분석 완료로 표시해서는 안 됩니다.

# TED–TRAP 최종 리뷰 반영 보고

2026-09-14. Leave-one-out을 본문·보충자료에 정식 보고한 최종 저자 검토본입니다. 다중 신호 공위치화는 이번 수정 범위에서 제외하고 모형 한계를 유지했습니다.

## 제목

**TSHR and IGF1R expression in Graves disease: Mendelian randomization and colocalization**

유전자 비교·발현 노출·MR·공위치화라는 실제 설계를 담았습니다. 주 분석은 GD이고 FinnGen도 안병증 환자 대 일반인 비교이므로, TED 고유 감수성을 직접 규명했다는 인상을 줄였습니다. TED의 임상적 의미는 초록·서론·Discussion에 유지했습니다. 본문·보충자료·커버레터·STROBE 표제를 동기화했습니다.

## 표와 통계의 보완

- Tables 1–3와 S1–S5를 제목·각주가 있는 개별 Word 파일로 제공하며, 본문/보충자료와 셀 단위로 일치합니다.
- Table 2에 H2를 추가했습니다. 초록에는 발현량 SD 단위를 명시했습니다. rs179252의 실제 G-allele 노출 계수는 0.10546, 질병 log-OR는 BBJ −0.22103 / UKB −0.25691 / FinnGen −0.24587입니다. 변이 수준 OR는 0.802/0.773/0.782로, SD 단위 MR OR와 다른 척도임을 각주에서 설명합니다. 리뷰에 적힌 근삿값을 복사하지 않았습니다.
- Table 3의 MAPKAPK5를 표 본문에서 0.977 (0.967–0.987)로 표시했습니다.
- Data 1–4를 보존하고, 모든 MR 추정법 13,039행을 담은 Data 5를 추가했습니다. 원래 효과 계수·SE·P값·진단 통계를 보존하며, 방법별 검정 분포와 일치하는 CI를 제공합니다. 복잡한 진단은 Supplementary에 두고 임상 독자는 OR·95% CI·P값을 먼저 읽도록 구성했습니다.
- 주 분석/빈도 시나리오의 추정 가능한 28,876행과 전체 추정법 13,039행의 P값을 각 분포로 대조했습니다. 이들은 중복 시나리오를 포함한 기록 수이며 독립된 발견 수가 아닙니다. 미추정 행은 음성으로 세지 않았습니다.

## Leave-one-out 최종 반영

- Methods·Results·Discussion에 사후 민감도 분석을 보고하고 Table 2 각주에 유럽계 CTLA4의 rs13030124 의존성을 명시했습니다.
- Table S5에 15개 제외 결과, Figure S2와 Data 6에 이 결과와 5개 전체 SNP 비교값을 제시했습니다. STROBE 항목 13의 미보고 문구를 수정했습니다.
- 15개는 IGF1R 11개와 CTLA4 4개입니다. IGF1R 11개 모두 OR>1이지만 BBJ/UKB는 각각 2개 제외 조건에서 P≥0.05였습니다. rs2654980 제외 시 P=0.0751/0.468이고, 이것만 유일한 비유의 제외 조건은 아닙니다.
- CTLA4에서 rs13030124를 제외한 UKB OR는 1.018 (95% CI 0.368–2.816), FinnGen OR는 1.717 (0.156–18.898)입니다. 정밀도가 낮으므로 다른 SNP가 무효과라고 단정하지 않았습니다. BBJ 단일-SNP 근거와 결합 공위치화 기준 미통과 판정은 변하지 않습니다.
- R 4.3.3의 별도 회귀/Wald 구현으로 9개 전체 추정치와 15개 제외 추정치를 재현했습니다. P값의 Python–R 최대 절대차는 4.44×10⁻¹⁶입니다. 원래 정렬된 자료를 재사용한 계산 검증이며, 새 표본의 독립 재현은 아닙니다.
- 기존 eQTLGen 빈도 민감도는 완료돼 있습니다. 새 LOO는 원래 참조 빈도에서만 시행했으며 그 범위를 명시했습니다.

## 유지한 한계와 저자 확인

새 다중 신호 공위치화는 수행하지 않았고 철회된 SuSiE 결과를 재사용하지 않았습니다. H3가 여러 독립 신호를 증명한다는 표현도 쓰지 않았습니다. 이것은 이번 제출 전 추가 필수 작업으로 남긴 항목이 아니라, 원고에 밝힌 모형 한계입니다. 향후 심사에서 구체적인 추가 검증이 필요해지면 적절한 LD 및 정렬 진단을 갖춘 새 분석으로 대응해야 합니다.

Steiger 방향성 검증은 시행하지 않았으며 eQTLGen–유럽계 outcome 참여자 중복도 정량화하지 못했습니다. 이를 검증 완료나 중복 0으로 표시하지 않았습니다. 이 한계들을 포함한 해석은 전 저자의 검토 대상입니다. 저자 정보·윤리/동의·연구비/이해상충·관련 원고 상태, 전 저자의 최종 승인, 실제 저널 요건과 포털 생성 PDF 확인이 남습니다. 원고 준비 완료와 모든 인과 가정의 입증은 구분합니다.

# Implementation clarifications, 2026-10-03

The original version-1 protocol is preserved, including its hash and 50 planned cells. These clarifications follow source-metadata inspection, before instrument selection and outcome analysis. No tissue or significance threshold is changed.

1. **GTEx ancestry wording:** The standard GTEx v8 release is multi-ancestry and predominantly European American (715/838 overall donors, 85.3%; not a tissue-specific fraction). The protocol's phrase "ancestry-aligned European exposure/outcome" was too strong for the standard release. We use the original standard v8 eQTL archive consistently for all five tissues, EUR reference LD, and European FinnGen as the primary outcome. This is predominantly European, not fully ancestry matched. The separately released EUR subset is not substituted after looking at results. This qualification must appear in reporting.
2. **Instrument availability versus full regional data:** The official free significant-pair archive is appropriate for instrument selection, as allowed by the protocol, but not for colocalization. The matching eGenes file contains all tested genes and their minimum nominal P value. We will verify whether its gene-specific release threshold includes all P<5e-8 candidate instruments, and distinguish a tested gene without qualifying variants from a gene not tested. If completeness at our selection threshold cannot be verified, report the input limitation rather than infer a negative result. The full regional all-pairs download is advertised in the official metadata as requester-pays. No billing project is configured and no paid retrieval is undertaken. Ancillary colocalization requires complete regional statistics; significant-only files will never be used for it.
3. **Units and effect allele:** Use the original slope and slope SE, with the original GRCh38 variant identifier and verified ALT-allele convention. These effects refer to normalized, inverse-normal-transformed expression, not TPM or pharmacological expression changes. MAF is not silently treated as ALT allele frequency. Ambiguous allele harmonization will use actual allele-labelled frequencies if available; otherwise unresolved palindromes are excluded.
4. **Independent verification:** Primary estimation will be independently checked against R base statistical functions and weighted regression. Previously installed specialist packages need not be available for a Wald/IVW calculation to be independently verified. No extra MR estimator is added because of a favourable result.

Sources: GTEx Consortium (2020), https://pmc.ncbi.nlm.nih.gov/articles/7737656/ ; official pipeline https://github.com/broadinstitute/gtex-pipeline/blob/master/qtl/README.md ; official download metadata archived in Sources/download_metadata.json; original v8 column documentation in Sources/readme.txt.
